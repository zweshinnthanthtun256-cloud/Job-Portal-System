# JobSphere အသုံးပြုသူလမ်းညွှန် (မြန်မာဘာသာ)

JobSphere သည် အလုပ်ရှာဖွေသူ၊ အလုပ်ရှင်နှင့် စနစ်စီမံခန့်ခွဲသူတို့အတွက် ပြုလုပ်ထားသော အလုပ်အကိုင် Portal ဖြစ်သည်။ Live demo ကို [https://jobsphere-demo.onrender.com](https://jobsphere-demo.onrender.com) တွင် အသုံးပြုနိုင်သည်။

> Render Free Plan ကိုအသုံးပြုထားသောကြောင့် အချိန်ကြာကြာအသုံးမပြုထားပြီးနောက် ပထမဆုံးဖွင့်ချိန်တွင် စက္ကန့် ၅၀ ခန့် စောင့်ရနိုင်သည်။ စာမျက်နှာကို ထပ်ခါတလဲလဲ Refresh မလုပ်ဘဲ ခဏစောင့်ပါ။

## ၁။ Account အမျိုးအစားများ

JobSphere တွင် Account သုံးမျိုးရှိသည်။

- **Job Seeker** — အလုပ်ရှာရန်၊ Profile ပြင်ဆင်ရန်၊ CV တင်ရန်၊ အလုပ်လျှောက်ရန်နှင့် Interview များကြည့်ရန်
- **Employer** — Company Profile စီမံရန်၊ Job Offer များတင်ရန်၊ Applicant များစစ်ဆေးရန်နှင့် Interview ချိန်းရန်
- **Administrator** — User၊ Company၊ Job၊ Report၊ Category၊ Skill နှင့် System Setting များစီမံရန်

## ၂။ Account အသစ်ဖွင့်ခြင်း

1. Home Page အပေါ်ညာဘက်ရှိ **Get started** ကိုနှိပ်ပါ။
2. **First name**, **Last name**, **Email address** နှင့် **Password** ကိုဖြည့်ပါ။
3. Account အမျိုးအစားအဖြစ် **Job seeker** သို့မဟုတ် **Employer** ကိုရွေးပါ။
4. Employer ရွေးထားပါက **Company name** နှင့် **Industry** ကိုထပ်ဖြည့်ပါ။
5. **Create account** ကိုနှိပ်ပါ။
6. Account ဖွင့်ပြီးပါက Dashboard သို့ အလိုအလျောက်ဝင်ရောက်သွားမည်။

Email verification နှင့် email ဖြင့် password reset ပို့ခြင်းကို ယခု portfolio demo တွင် မသုံးထားပါ။ မိမိ Password ကို သေချာမှတ်သားထားပါ။

## ၃။ Login နှင့် Logout

### Login ဝင်ရန်

1. **Log in** ကိုနှိပ်ပါ။
2. Account ဖွင့်စဉ်က အသုံးပြုထားသော Email နှင့် Password ကိုထည့်ပါ။
3. **Log in** ခလုတ်ကိုနှိပ်ပါ။

### Logout ထွက်ရန်

Dashboard အပေါ်ညာဘက်ရှိ ထွက်ရန်ပုံစံ ခလုတ်ကိုနှိပ်ပါ။ Mobile တွင် အပေါ်ဘယ်ဘက် Menu ကိုဖွင့်ပြီး Navigation များကိုကြည့်နိုင်သည်။

## ၄။ Job Seeker အသုံးပြုနည်း

### Profile ပြည့်စုံအောင်ဖြည့်ခြင်း

1. Dashboard Menu မှ **Profile** ကိုဖွင့်ပါ။
2. အမည်၊ Headline၊ Current position၊ Phone၊ City၊ Country နှင့် Career summary ကိုဖြည့်ပါ။
3. **Save profile** ကိုနှိပ်ပါ။
4. **Profile photo** တွင် JPG, PNG သို့မဟုတ် WebP ပုံတင်နိုင်သည်။ ပုံအရွယ်အစား 2 MB ထက်မကျော်ရပါ။
5. **Skills** တွင် ရှိပြီးသား Skill ကို Checkbox ဖြင့်ရွေးနိုင်သလို မိမိ Skill အသစ်ကို ရိုက်ထည့်ပြီး **Add** နှိပ်နိုင်သည်။
6. **Resume** တွင် PDF ဖိုင်ကိုတင်နိုင်သည်။ ဖိုင်အရွယ်အစား 5 MB ထက်မကျော်ရပါ။
7. **Education**, **Experience**, **Languages** နှင့် **Certifications** အပိုင်းများတွင် လိုအပ်သောအချက်အလက်များဖြည့်ပြီး ထည့်သွင်းပါ။

Profile အပေါ်ပိုင်းရှိ **Profile completion** ရာခိုင်နှုန်းကိုကြည့်ပြီး လိုနေသောအချက်များကို ဖြည့်နိုင်သည်။ Profile ပိုပြည့်စုံလေလေ Job Recommendation ပိုကောင်းလေလေ ဖြစ်သည်။

### အလုပ်ရှာခြင်း

1. **Browse jobs** သို့မဟုတ် **Find jobs** ကိုဖွင့်ပါ။
2. Job title/keyword၊ Location၊ Category နှင့် Work type တို့ဖြင့် ရှာနိုင်သည်။
3. စိတ်ဝင်စားသော Job Card ကိုနှိပ်ပြီး Job Detail ကိုဖွင့်ပါ။
4. Company အမည်ကိုနှိပ်ပါက Company Public Page ကိုကြည့်နိုင်သည်။

### အလုပ်သိမ်းထားခြင်း

Job Detail Page တွင် **Save job** ကိုနှိပ်ပါ။ သိမ်းထားသောအလုပ်များကို Dashboard Menu ရှိ **Saved jobs** တွင်ကြည့်နိုင်သည်။ **Remove saved job** ကိုနှိပ်၍ ပြန်ဖယ်နိုင်သည်။

### အလုပ်လျှောက်ခြင်း

1. လျှောက်လိုသော Job Detail Page ကိုဖွင့်ပါ။
2. Cover letter နှင့် Expected salary ကိုလိုအပ်သလိုဖြည့်ပါ။
3. **Submit application** ကိုနှိပ်ပါ။
4. တင်ပြီးသော Application ကို **Applications** စာမျက်နှာတွင် Status Timeline နှင့်အတူကြည့်နိုင်သည်။
5. ဆက်လက်မလျှောက်လိုပါက ခွင့်ပြုထားသော Status အတွင်း **Withdraw** ကိုနှိပ်နိုင်သည်။

Job တစ်ခုတည်းကို နှစ်ကြိမ်လျှောက်၍မရပါ။ Deadline ကျော်သွားသော၊ Pause/Close လုပ်ထားသော Job ကိုလည်း လျှောက်၍မရပါ။

### Recommendation၊ Interview နှင့် Notification

- **Recommended jobs** တွင် Profile Skill နှင့် Experience ကိုအခြေခံထားသော Job များကိုကြည့်နိုင်သည်။
- **Interviews** တွင် Interview ရက်၊ အချိန်၊ Timezone၊ Type နှင့် Meeting Link/Location ကိုကြည့်နိုင်သည်။
- **Notifications** တွင် Application Status နှင့် Interview Update များကိုကြည့်နိုင်သည်။ **Mark all read** ဖြင့် အားလုံးဖတ်ပြီးအဖြစ် သတ်မှတ်နိုင်သည်။

## ၅။ Employer အသုံးပြုနည်း

### Company Profile ပြင်ဆင်ခြင်း

1. Dashboard Menu မှ **Company** ကိုဖွင့်ပါ။
2. Company name၊ Industry၊ Size၊ Contact၊ Address၊ Website၊ Description၊ Culture နှင့် Benefits ကိုဖြည့်ပါ။
3. **Save company** ကိုနှိပ်ပါ။
4. Logo နှင့် Cover image ကို **Brand images** အပိုင်းမှတင်နိုင်သည်။
5. **View public page** ဖြင့် အများမြင်ရမည့် Company Page ကို Preview ကြည့်နိုင်သည်။

### Team Member ထည့်ခြင်း

1. ထည့်မည့်သူသည် Employer Account ရှိပြီးသားဖြစ်ရမည်။
2. **Team members** အပိုင်းတွင် သူ၏ Email ကိုထည့်ပါ။
3. **Recruiter** သို့မဟုတ် **Company admin** Role ကိုရွေးပါ။
4. **Add member** ကိုနှိပ်ပါ။

Owner ကို ဖယ်ရှား၍မရပါ။ Recruiter သည် Company Admin အသစ်ထည့်ရန် ခွင့်မရှိပါ။

### Job Offer ဖန်တီးခြင်း

1. **Manage jobs** ကိုဖွင့်ပါ။
2. Company၊ Job title၊ Category၊ Description၊ Work arrangement၊ Experience နှင့် Deadline ကိုဖြည့်ပါ။
3. ချက်ချင်းတင်လိုပါက **Publish immediately** ကိုရွေးပါ။
4. **Create job** ကိုနှိပ်ပါ။

Job တစ်ခုစီတွင် အောက်ပါလုပ်ဆောင်ချက်များရှိသည်။

- **Edit** — Job အချက်အလက်များပြင်ရန်
- **Preview** — Public Page ကိုကြည့်ရန်
- **Duplicate** — Job အသစ်အဖြစ် မိတ္တူကူးရန်
- **Pause / Resume** — လျှောက်လွှာလက်ခံမှုကို ယာယီရပ်/ပြန်ဖွင့်ရန်
- **Close** — လျှောက်လွှာလက်ခံမှု ပိတ်ရန်
- **Archive** — မှတ်တမ်းအဖြစ် သိမ်းရန်
- **Delete** — Application မရှိသေးသော Job ကိုဖျက်ရန်

### Candidate စီမံခြင်း

1. **Candidates** ကိုဖွင့်ပါ။
2. Applicant အမည်၊ Email၊ Job နှင့် လက်ရှိ Status ကိုကြည့်ပါ။
3. Status ကို Viewed, Under review, Shortlisted, Interview scheduled, Offered, Hired သို့မဟုတ် Rejected အဖြစ် ပြောင်းနိုင်သည်။
4. Applicant တင်ထားသော Resume ကို ခွင့်ပြုချက်ရှိသော Employer သာ Download လုပ်နိုင်သည်။

### Interview စီစဉ်ခြင်း

1. Candidate စာမျက်နှာမှ Application အတွက် Interview ဖန်တီးပါ။
2. Date၊ Start time၊ End time၊ Timezone နှင့် Interview type ကိုဖြည့်ပါ။
3. Video Interview ဖြစ်ပါက Meeting URL ထည့်ရမည်။
4. **Interviews** စာမျက်နှာတွင် Interview ကို ပြင်နိုင်သလို အကြောင်းပြချက်ဖြင့် Cancel လုပ်နိုင်သည်။

Interviewer သို့မဟုတ် Candidate တစ်ဦးတည်းအတွက် အချိန်တူ Interview နှစ်ခု ထပ်နေပါက စနစ်က လက်မခံပါ။

## ၆။ Administrator အသုံးပြုနည်း

Administrator သည် **Admin console** မှ အောက်ပါလုပ်ဆောင်ချက်များကို ဆောင်ရွက်နိုင်သည်။

- User အရေအတွက်၊ Company၊ Job၊ Application နှင့် Open Report Analytics ကြည့်ခြင်း
- Site name၊ Support email၊ Maintenance message နှင့် Application ဖွင့်/ပိတ် Setting ပြင်ခြင်း
- Category နှင့် Skill အသစ်ထည့်ခြင်း သို့မဟုတ် အသုံးမပြုတော့သည်ကိုဖျက်ခြင်း
- User ကို Active/Suspended ပြောင်းခြင်း
- Company ကို Pending/Verified/Rejected/Suspended ပြောင်းခြင်း
- Job ကို Published/Paused/Closed/Archived ပြောင်းခြင်း
- Report ကို Reviewing/Resolved/Dismissed ပြောင်းပြီး Resolution Note ထည့်ခြင်း
- Audit Trail မှ အရေးကြီးလုပ်ဆောင်ချက်များကို စစ်ဆေးခြင်း

အသုံးပြုနေသော Category သို့မဟုတ် Skill ကို တိုက်ရိုက်ဖျက်၍မရပါ။

## ၇။ Mobile အသုံးပြုနည်း

- Public Page တွင် အပေါ်ညာဘက် **Menu** ခလုတ်ကိုနှိပ်၍ Navigation ကိုဖွင့်ပါ။
- Dashboard တွင် အပေါ်ဘယ်ဘက် **Menu** ခလုတ်ကိုနှိပ်၍ Role အလိုက် Menu များကိုဖွင့်ပါ။
- Admin နှင့် Candidate Table များသည် Mobile တွင် Card အတွင်း အလျားလိုက်ရွှေ့ကြည့်နိုင်သည်။ စာမျက်နှာတစ်ခုလုံး အလျားလိုက်ရွှေ့စရာမလိုပါ။

## ၈။ အမှားဖြေရှင်းခြင်း

### Page ဖွင့်ရာတွင် ကြာနေခြင်း

Render Free Server ပြန်နိုးလာရန် စက္ကန့် ၅၀ ခန့်ကြာနိုင်သည်။ ခဏစောင့်ပြီးမှ တစ်ကြိမ် Refresh လုပ်ပါ။

### Login မဝင်နိုင်ခြင်း

- Email စာလုံးပေါင်းနှင့် Password ကိုပြန်စစ်ပါ။
- Password တွင် စာလုံးအကြီး/အသေးကွာခြားသည်။
- Suspended Account ဖြစ်ပါက Administrator ကိုဆက်သွယ်ပါ။

### Job Apply မရခြင်း

- Job Seeker Account ဖြင့် Login ဝင်ထားကြောင်းစစ်ပါ။
- Job Deadline၊ Status နှင့် ယခင်လျှောက်ထားမှုရှိ/မရှိ စစ်ပါ။
- Administrator က Application လက်ခံမှုကို ယာယီပိတ်ထားနိုင်သည်။

### File တင်မရခြင်း

- Resume သည် PDF နှင့် 5 MB အောက်ဖြစ်ရမည်။
- Profile photo သည် JPG, JPEG, PNG သို့မဟုတ် WebP နှင့် 2 MB အောက်ဖြစ်ရမည်။
- Company image သည် 4 MB အောက်ဖြစ်ရမည်။

## ၉။ လုံခြုံရေးအကြံပြုချက်

- မိမိ Password ကို အခြားသူအားမပေးပါနှင့်။
- Public Computer တွင်အသုံးပြုပြီးပါက Logout ထွက်ပါ။
- Resume နှင့် ကိုယ်ရေးအချက်အလက်များကို လိုအပ်သလောက်သာ ထည့်ပါ။
- သံသယဖြစ်ဖွယ် Job ကို Report လုပ်ပြီး ကိုယ်ရေးအချက်အလက် ထပ်မပေးပါနှင့်။
